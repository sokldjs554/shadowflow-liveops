# Evaluation contract

Measured results are generated by `python scripts/evaluate.py` and written to `artifacts/evaluation.json`.

The benchmark is synthetic and answers narrow engineering questions:

- Does the first selector-heavy compile pass the recorded UI but fail changed DOM identifiers?
- Does evidence-based semantic repair pass the same UI-drift variants?
- Does publish remain approval-gated after repair?
- Does the generated code contain the approval guard and semantic Playwright locators?
- Does the API-backed pipeline produce the same verdict repeatedly?

It does **not** measure:
- real employee time savings;
- real website/browser-agent success rate;
- Qwen/Claude/OpenAI model quality;
- GameSpring production workflows or traffic;
- production-scale latency.
