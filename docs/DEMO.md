# Demo walkthrough

The demo is intentionally a product console rather than a portfolio landing page or chat window.

1. Click **Run demonstration**.
2. The UI loads an 11-event synthetic multilingual live-ops trace.
3. Attempt 1 compiles the captured generated CSS selectors and passes the baseline twin.
4. Three changed-DOM twins reject the brittle selector workflow.
5. The repair promotes recorded accessibility semantics (`role + accessible name`, or label for file upload).
6. Attempt 2 runs the exact same baseline/drift matrix.
7. A deterministic risk policy marks `Publish event` as an external write requiring human approval.
8. The product generates Playwright TypeScript from the verified typed workflow.
9. **Approve generated automation** changes only the export verdict. It does not perform a real publish.

The reviewer can inspect the observed trace, compiled steps, two-attempt shadow matrix, pipeline log, evidence packet, risk decision, and generated code without opening a chat interface.
