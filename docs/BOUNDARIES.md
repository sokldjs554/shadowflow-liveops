# Boundaries and claims

- The synthetic live-ops workspace is independently designed from public information about a global mobile game company. It is **not** a reconstruction of GameSpring's private admin tools or internal workflow.
- No real player, payment, gambling, account, or employee data is used.
- A shadow `publish` mutates only an in-memory synthetic twin. The demo never sends a player-visible update.
- The deterministic compiler is a reproducibility harness, not a claim about LLM quality.
- OpenAI-compatible and hosted Messages API adapters demonstrate integration contracts. Real Qwen/Ollama/vLLM/hosted-model quality must be measured separately before making model-performance claims.
- UI-drift results are synthetic robustness measurements, not production website success rates.
